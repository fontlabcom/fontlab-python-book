# FontLab Scripting Book

This book is in preparation. Twenty-five introductory chapters are available as drafts; the complete manuscript has not been written or reviewed.

Start with [Fonts, FontLab and Python](01-fonts-fontlab-and-python.md). It introduces the main terms and a one-line Python exercise, with links to its documentation sources.

Continue with [Python basics for a small report](02-python-basics.md), using fictional data to learn values, names, collections, conditions, loops, functions and errors.

Then [Understand the font data before you script it](03-understand-font-data.md): distinguish glyph identity, drawing layers, outline structure and spacing before choosing an operation.

Next, [Work in the Scripting panel](04-work-in-the-scripting-panel.md): preserve and run a small script, verify its saved file, and distinguish errors, output and execution limits.

Then [Inspect the current font](05-inspect-the-current-font.md): distinguish API objects, handle a missing font, and read a glyph count and a few names in a source-checked example with bounded native verification.

Continue with [Find the glyph you mean](06-find-the-glyph-you-mean.md): distinguish names, indices and Unicode assignments, then run a complete unencoded/shared-assignment report with bounded native verification.

Next, [Choose the drawing before counting its points](07-choose-the-drawing.md): practise layer-scoped reports with fictional Python data and distinguish stored points from native wrappers.

Then [Keep a recoverable source before you change a font](08-keep-a-recoverable-source.md): distinguish proposals, updates, history and saved files, with a Python exercise that applies no changes.

Next, [Say which glyphs your report covers](09-report-selected-glyphs.md): count selected cells and distinct glyphs separately, and practise a traceable report using fictional Python records.

Then [Keep reusable code separate from its launcher](10-organize-reusable-scripts.md): run a two-file external Python project and distinguish menu files, shared packages and extension bundles.

Next, [Choose the host before choosing the UI](11-choose-a-ui-approach.md): compare native and external UI routes and prepare preview text without opening a window.

Then [Transform a drawing before changing a font](12-transform-a-recording.md): understand pen protocols and coordinate mappings through a fictional recording, and distinguish the native adapters' write boundaries.

Next, [Report the spacing decision before changing it](13-report-kerning-proposals.md): distinguish explicit and effective kerning, master scope, zero and absence through a fictional proposal-only report.

Then [Plan an attachment before building it](14-plan-an-attachment.md): distinguish components, anchors and automatic construction, and calculate fictional master-specific placement proposals.

Next, [Identify the location before calculating a design](15-identify-the-location.md): separate coordinate systems and kinds of instance, then calculate a fictional width along one linear axis.

The planned book will cover FontLab scripting in depth. Corpus processing, the private semantic map and its integration into the book remain pending. Broader source research, independent editorial review and native example validation are incomplete. These introductory drafts do not establish comprehensive coverage or completion of the book.

Next, [Check the names and code that reach the output](16-check-output-records.md): compare fictional full naming-record keys and separate stored feature source from compiled layout and exported files.

Then [Test the promise, then test the host](17-test-the-promise.md): run fictional tests, inspect failures and distinguish offline checks from native UI and saved artifacts.

Next, [Choose the TypeRig layer before copying an example](18-choose-the-typerig-layer.md): distinguish core geometry, live wrappers, GUI entry points and versioned packages.

Then [Know where the automation runs](19-know-where-automation-runs.md): separate external clients, native interfaces and capture tools, then classify fictional completion records without making a request.

Next, [Share the files and the conditions](20-share-the-files-and-conditions.md): distinguish packages, menu files and Extensions bundles, then compare fictional delivered bytes against a recorded inventory.

Then [Make the report reproducible](21-make-the-report-reproducible.md): keep path ownership, JSON/CSV meaning, exact bytes and output completion distinct through an in-memory reporting exercise.

Next, [Measure the space and the drawing separately](22-measure-space-and-drawing.md): distinguish advance, geometric bearings and kinds of bounds through fictional arithmetic, with explicit native getter limits.

Then [Name the targets before running the batch](23-name-the-batch-targets.md): build a fictional target proposal and distinguish action ordering, partial edits and cancellation boundaries.

Next, [Keep values separate from live handles](24-keep-values-separate-from-handles.md): compare aliases, shallow copies and selected-value records, then distinguish native ownership from persistence.

Then [Character mapping is not shaping](25-mapping-is-not-shaping.md): distinguish assignments from shaping, then check sample text with a complete FontLab metadata-report project with bounded native verification.
